# Art kit and provenance

`manifest.json` records the source Crown & Dust commit, original relative path, role, byte count and SHA-256 of every copied file. `npm run check` verifies these copies. Original Tiny Castle brand provenance is preserved in `brand/tiny-castle/provenance.json` with the original Git blob hashes.

Fonts, six GLBs, eight portraits, original code and reference PNGs are included so Claude does not have to infer the look from prose. Gawain and Merlin have portrait/procedural source rather than GLB files. Reference source files retain historical imports; they are examples to study, not modules to import without adaptation.

These are the user's existing owned art and properly noticed runtime/fonts. See `../NOTICE.md`. No third-party reference game's visual assets were downloaded into this kit.
