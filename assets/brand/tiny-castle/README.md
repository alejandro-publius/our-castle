# Tiny Castle brand artwork

Reused at the author's explicit request from their older Tiny Castle project:
https://github.com/alejandro-publius/tiny-castle

The five lossless WebP images are unchanged. Their SHA-1 Git blob hashes, source paths and pinned commit are in `provenance.json`. Downloads from the published rehearsal were checked against the connected repository's hashes. No prior game code or playable geometry was copied.

Roles in Crown & Dust:

- Logo: parent branding; retain the original aspect ratio and alpha.
- Red crest: the player; blue crest: the house. Team identity is separate from RPS type.
- Dragon badge: decorative world branding, not an unlocked-reward claim.
- Victory banner: completed player wins only; score and outcome remain real HTML text.

The original project describes the images as the author's ImageGen brand artwork, derived from their approved gold/ivory brand board. They are raster images, not rigged models or vectors. The new card game's models and portraits are generated separately.
