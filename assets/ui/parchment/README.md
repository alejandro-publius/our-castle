# Painted parchment skin

The owner requested a tangible, illustrated game interface for both the Journal and Village Exchange, using the OpenAI image generator. `woodland-panel.webp` is an original generated empty parchment panel with a carved woodland frame. It is decorative; names, quantities, receipts, approvals, forms and buttons remain real application elements.

The frame is used as a scalable CSS border image. Its paper center is deliberately quiet beneath readable dark ink. Phone layouts retain 44px actions, native form controls and the existing dialog/tab behavior. No copyrighted game screenshot was imported as an asset. Existing Our Castle identity art and world art are separate and unchanged.

`provenance.json` records the original generated PNG hash, output hash and WebP encoding. The original PNG remains in the generation workspace; the optimized asset is served locally, without a CDN or new runtime dependency. Generated artwork is not a photograph or evidence of a real household, listing or transaction.
