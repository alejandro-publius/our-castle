# Demo script (under 3 minutes)

Record only after the live checks in [VALIDATION.md](VALIDATION.md) pass with real sandbox and AI credentials, so the video shows the real integrations, not example mode. Use the sandbox app and a sandbox buyer account; never show the `.env` file, client secret or API key. Use no third-party music or trademarks other than the PayPal sandbox checkout the product integrates. The final publish/upload/submit decisions belong to the repository owner.
