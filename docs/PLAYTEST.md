# Three-person playtest

Use `npm run demo` for a fresh, simulated household per person. The observer should give the tasks, then watch without explaining the interface. No actual payment, key, account or real financial data is needed. These are planned sessions, not completed user research.

1. “Name your house, pick a character, and find what you're working toward.”
2. “You have $60 toward the $300 camping trip. Find the next area and use the demo to add enough to reach it.”
3. “Show the record of what you added. Visit your new area, then refresh and find that record again.”

Record time to each result, where the person hesitates, whether help was needed and their exact words. Ask one final question: “What did you think the payment did?” A clear answer should distinguish simulated goal progress from buying a product, a bank balance or paying a utility bill. Do not teach that answer before asking.
